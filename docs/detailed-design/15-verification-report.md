## 4. 生产者—消费者与冲突审查

- 16 的 Schema 注册表逐项给出生产者和消费者；合同测试要求使用真实生产者输出再由真实消费者读取。
- Strategy 只消费历史 Slice 和可选 CustomFactorView，不读取路径、系统时间、模拟账户、AccountSnapshot 或上一目标。
- Target、模拟账户实际持仓和真实 AccountSnapshot 是三种独立状态；Daily 不维护影子账户。
- Backtest 卖出实际成交后才把净收入用于买入；Daily Advice 只使用快照当时可用现金。
- Research、Execution、Valuation、Reference 四种价格用途分离；公司行为只进入执行和估值，不被研究价格重复计入。
- 理论回撤使用基础目标的无费用自然漂移净值；正式最大回撤使用实际模拟账户全期运行峰值，两者字段和公式不混用。
- `cash_cost_contribution` 在指标公式与物理 Schema 中同名，且必须与股票、ETF 贡献共同守恒。
- 用户因子不复制到 Research，不验证其计算逻辑或历史可见性，正式结果固定披露责任限制。
