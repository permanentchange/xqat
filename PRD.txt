# XQatExp 产品范围与功能说明

XQatExp 是本地 A 股量化研究与决策 CLI。它通过显式输入、版本化数据和可校验结果，
连接数据获取、研究准备、策略回测和每日决策。产品说明以当前代码、Schema 和可执行测试为依据。
操作入口见 README.md，架构见 docs/architecture.md，数据流程见 docs/data.md。

## 运行方式

运行时为 CPython 3.12，使用独立 Conda 环境。Linux x86_64 为主 CI 平台，
Windows 10/11 x64 为兼容性目标。项目是纯 Python 模块化单体，以本地文件交换数据。
CLI 和 python -m xqatexp 提供同一入口；输出路径由用户显式指定。

## 数据准备

- Tushare 注册 15 个 canonical dataset，通过 HTTP API 获取数据。
- 单次 fetch 发布一个 Raw Artifact；fetch-batch 用共享 Client、连接池、全局/API 限流器和 1–8 workers 执行分区。
- 股票日频按真实 SSE 交易日规划，income/fina_indicator 按报告期调用对应 VIP 全市场接口。
- batch 支持校验跳过、补洞、失败续跑、窗口刷新、不可变代次及统一 batch-result.json。
- Provider 和 batch plan 分别使用独立 TOML；Token 只由 TUSHARE_TOKEN 注入。
- Raw Collection 索引包含请求身份、代次、相对路径、哈希和声明覆盖；同目录只允许一个写入者。
- 完整 Collection 或显式 Raw roots 经 ResearchBuilder 转换成七张 Parquet 表。
- Raw 增量获取后，Collection 路径从完整历史重建 Research；data update 支持 Research base 与显式 Raw 合并。
- 财务保留披露版本；同业务键不同事实报冲突。窗口外财务修订需要显式扩大刷新范围。

## 研究与策略

ResearchSession 使用进程内 DuckDB，按决策日期、available_from 和声明 lookback 限制数据访问。
策略不得直接读取 Raw 或请求网络。Readiness 按 StrategyDeclaration 的数据覆盖检查。
用户 CSV 因子固定列为 factor_name,security_id,factor_date,factor_value；其计算逻辑由用户负责。

内置策略均通过 Strategy Registry 注册：

- weekly_market_guard_rank_v1@1.0.0：周频 allocation，市场状态、股票横截面评分、持仓滞回和理论组合回撤控制。
- staged_drawdown_v1@1.0.0：日频单证券 TradeIntent，缓慢下跌建仓、相对实际买入价加仓和整体持仓止盈。

参数及边界见各策略源码目录 README。Backtest 与 Daily 使用相同策略实现。

## 回测

决策在收盘后产生，最早在下一交易日执行。NEXT_OPEN 模型使用 raw open、滑点、价格刻度、
日内高低/涨跌停边界、成交量参与上限、交易手数、现金、可卖持仓和费用约束。
账户推进 A 股 T+1、现金分红、送股和拆分；不支持或无法精确表达的持仓公司行为明确失败。

回测结果包含交易、未成交、每日组合、目标历史、收益/回撤/风险指标、阶段分析、诊断及 Markdown 报告。
stateful 回测保存最终 StrategyState。没有成交仍可发布成功回测；命令失败不会伪装为部分成功结果。

## 每日决策与账户

- daily target：为 allocation 策略生成目标权重。
- daily decide：为要求 confirmed state 的策略生成下一交易日 TradeIntent；必须显式提供策略状态。
- daily advise：读取已发布 target，可结合 AccountSnapshot 生成研究参考数量。
- state init/apply-fill/apply-stock-adjustment：创建状态或应用已确认成交、送股、拆分事实。

AccountSnapshot 显式记录策略管理范围、完整性、现金、资产和持仓。缺失事实保持 unresolved。
系统不从目标、建议或模拟账户推测真实持仓；intent 不代表成交，advice 不代表订单。

## 结果、可靠性与边界

Raw、Research、Daily、Backtest 和 Failure Diagnostic 使用版本化 Manifest、Schema 和 SHA-256。
Artifact 发布采用同目录 staging、校验、rename 和显式覆盖恢复；Collection 索引/报告独立原子更新。
配置拒绝秘密字段，日志/错误脱敏，输入输出互不重叠，输出和 Collection 路径拒绝危险链接。

普通测试使用确定性本地数据。Live Tushare 测试需显式 Token 与 --live-tushare。
Linux CI 的功能测试、80% coverage、CLI help 和 offline self-check 为门禁；Ruff/Mypy 和 Windows job 为 advisory。

产品不提供 Web 服务、券商下单、自动账户同步、实时行情或集合竞价订单簿撮合。
限流不跨进程协调，VIP 权限/分页失败不自动替代，增量窗口外的修订不会自动发现。
平台目标和实现范围不代表特定账号权限、数据覆盖或真实网络性能已经验证。
